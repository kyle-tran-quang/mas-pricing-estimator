# MAS Pricing Estimator (Figma Make Prototype)

This is a local React + Vite + Tailwind CSS application extracted from a Figma Make prototype.

## Prerequisites

- Node.js (v18 or higher recommended)
- npm (or pnpm / yarn)

## Getting Started

1. **Install dependencies:**

   ```bash
   npm install
   ```

2. **Start the local development server:**

   ```bash
   npm run dev
   ```

3. **Open the application:**
   Navigate to [http://localhost:5173](http://localhost:5173) in your browser.

## Available Scripts

- `npm run dev` - Start local Vite development server with Hot Module Replacement (HMR)
- `npm run build` - Build production bundle in `dist/`
- `npm run preview` - Preview production build locally
- `npm run format` - Format code with oxfmt
